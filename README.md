# Early Detection of Combustion Instability with Machine Learning

Rocket Propulsion term project, IIT Kharagpur.
Harshvardhan Singh Chauhan (23AE30007), Vedaant Gupta (23AE3AI46), Pawan Sharma (23AE10024).

3-class detection (Stable / Transition / Unstable) from 50 ms windows of chamber pressure p′ and
flame light q′ sampled at 10 kHz. The project compares RMS thresholds, SVM and Random Forest
on 5 hand-made features against a 1D-CNN and CNN-LSTMs on the raw waves. It measures accuracy,
false alarms, warning time before full instability, and latency.

## Setup

```bash
pip install numpy scipy scikit-learn openpyxl matplotlib "jax[cpu]" flax optax
```

## Run everything (about 25 min on a 2-core laptop CPU)

```bash
python make_dataset.py      # 15 slow φ-sweeps (44,940 windows) + 12 fast lean-outs -> data/
python train_classical.py   # RMS rules, SVM, RF, window-length study -> results/classical.json
python train_deep.py cnn     # 1D-CNN on raw p′
python train_deep.py lstm_p  # CNN-LSTM on raw p′ (200 ms of history)
python train_deep.py lstm_pq # CNN-LSTM on p′ + q′ (sensor fusion)
python evaluate.py          # thresholds on validation runs, test metrics -> results/summary.json
python real_check.py         # public real recordings in real_data_TestingData/ (see below)
python browser_forest.py    # compact RF for the in-browser simulator
python export_web.py && python build_web.py  # -> web/index.html (self-contained demo site)
```

Open `web/index.html` in any browser. It needs no server.

## Files

| File | What it does |
|---|---|
| `simulator.py` | Reduced-order thermoacoustic combustor: one acoustic mode as a noise-driven oscillator with an n-τ flame, Rayleigh driving β cos θ(φ) − α, subcritical saturation, turbulent flame-gain fluctuations, 0.5 ms waveguide, photodiode q′. |
| `features.py` | 50 ms / 10 ms windowing and the 5 features: RMS, kurtosis, FFT peak ratio, zero-crossing regularity, p′–q′ phase lag (waveguide-corrected). |
| `common.py` | Loading, alarm logic (3 windows on / 10 off), warning time, false-alarm metrics, threshold tuning. |
| `train_classical.py`, `train_deep.py` | Model training. Deep models use JAX/Flax on CPU. |
| `evaluate.py` | Unified evaluation, false-alarm vs recall trade-off, quiet-gap analysis. |
| `real_check.py` | External check on 42 public combustor recordings. |
| `web/` | Demo website: `core.js` is a JavaScript port of the simulator, features and RF (checked against Python to 1e-7). |

## Data sources

* **Main study (simulated):** generated by `simulator.py`, designed to match report §4.2:
  15 runs × 30 s, φ 0.90 → 0.55, 10 kHz, 210 Hz quarter-wave mode, 70/15/15 split by whole run
  (11/2/2). Ground-truth regimes come from the model's mean growth rate ν:
  Stable ν < −2 s_ν, Transition −2 s_ν ≤ ν < 0, Unstable ν ≥ 0.
* **External check (real recordings):**
  github.com/Hashim-mirjan/combustion-stability-classifier-mech0020, folder `TestingData/`
  (14 stable, 14 transient, 14 limit-cycle recordings, 0.5 s each at 10 kHz). The repository
  does not document where the recordings come from.

## Limits

The main data is simulated, so its parameters are set to the report's numbers rather than
fitted to a real rig. The real recordings have no q′ channel and no time history, so they cannot be
used to measure warning time. The flame-image 2D-CNN track is not included.
